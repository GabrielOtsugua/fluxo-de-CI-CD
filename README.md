# Aprendendo a editar um README

Guia rápido

- Títulos
- Listas e checklist de tarefas
- Blocos de códigos formatados
- Badges (Escudos de status)
- Imagens e gifs
- Bônus

## Títulos

```bash
# Seu título principal
## Seu subtítulo
### Sua seção secundária
```

## Listas e checklist de tarefas

```json
* Item da lista 1
* Item da lista 2

- Item checklist 1
- Item checklist 2
```

## Blocos de códigos formatados

````json
" ```Seu código´´´ "
````

Obs: Use apenas as crases.

## Badges (Escudos de status)

```json
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow)
![License](https://img.shields.io/badge/Licenca-MIT-blue)
```

## Bônus

Escrevendo em negrito e itálico.

```json
*Itálico*
**Negrito**
***Itálico e negrito***
```
