# Aprendendo a editar um README

## Guia rápido

- Títulos
- Listas e checklist de tarefas
- Blocos de códigos formatados
- Badges (Escudos de status)
- Imagens e gifs

## Títulos

Use esse padrão para escrever títulos:

```bash
# Seu título principal
## Seu subtítulo
### Sua seção secundária
```

## Listas e checklist de tarefas

Use esse padrão:

```
* Item da lista 1
* Item da lista 2

- Item checklist 1
- Item checklist 2
```
